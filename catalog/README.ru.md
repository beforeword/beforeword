# beforeword для Claude и OpenAI

[English](README.md) · [Примеры](examples.md) · [Исходная инструкция](../assets/core.ru.txt)

**Что добавляет прочтение**

ИИ пишет «я понимаю». Эти слова читают как понимание. На каком основании?

Сборка для каталогов включает полное ядро beforeword 1.3.4. Текст внутри пакета — английский; язык ответа можно задать в запросе. Русские описания и примеры включены. Для каждой платформы предусмотрена одна карточка beforeword.

## Первый запуск

Выбери beforeword там, где приложение предлагает выбор плагина или навыка, и вставь фразу либо ответ ИИ. Например:

> Примени beforeword к фразе «Я понимаю». Покажи также, что добавляет само объяснение.

Для английского:

> Apply beforeword to “I understand.” Include what your own explanation adds.

[Составленные примеры](examples.md) показывают предлагаемый разбор. Это иллюстрации, а не записи ответов Claude или ChatGPT.

## Сборка и проверка

Из корня репозитория:

```bash
python3 -B scripts/test_release_contract.py
python3 -B catalog/build.py --write
python3 -B catalog/check.py
python3 -B catalog/build.py --check
python3 -B scripts/check_release_sources.py --generated
```

[release-contract.json](../references/release-contract.json) связывает номер релиза с хэшами выбранного ядра RU/EN. Сборка прекращается, пока выбор не записан или хэш одного из исходников отличается. Номер версии находится в метаданных и не добавляется к точному тексту ядра. Для обёрток навыка и отдельно редактируемых кратких инструкций предусмотрено сравнение байтов. Загрузки и ZIP прошлых версий сохраняются.

Сборка не обращается к модели, не устанавливает навык, не подключает аккаунт и не отправляет заявку. Проверка файлов, испытание в приложении и рассмотрение каталогом учитываются отдельно.

[Порядок подачи и ссылки на документацию](SUBMISSION.md) перечисляют нужные пути и следующие действия владельца.

Русский перевод включён в метаданные OpenAI. Согласно текущей документации OpenAI, импортированные переводы сохраняются, но пока не меняют отображаемый текст каталога. Поэтому русский README также находится внутри пакета.

[Сообщить о проблеме](https://github.com/beforeword/beforeword/issues). Приложи запрос, ответ, обозначение среды и модели, версию пакета и способ подключения; предварительно удали личные данные.
