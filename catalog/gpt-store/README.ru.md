# beforeword · заготовка GPT

[English](README.md) · [Статус публикации](../SUBMISSION.md)

Поля для создания GPT подготовлены. Сам GPT не создан, ссылка на него не опубликована, размещения в Store нет. Доступ к конструктору, ограничения полей и возможность публичной публикации нужно проверить в аккаунте владельца.

## Заполнение

1. Название: `beforeword`.
2. Описание и три стартовых запроса возьми из [draft.json](draft.json). В файле есть английская и русская редакции.
3. Вставь целиком [английскую](instructions.en.txt) или [русскую](instructions.ru.txt) инструкцию в поле Instructions. Выбери одну редакцию. В каждом файле — область действия и явно сокращённая редакция 1.3.1 до 5 000 знаков. Точная длина итогового текста и пути исходников записаны в `draft.json`. Пакеты Claude и OpenAI содержат полную основную инструкцию.
4. Для значка используй [знак проекта в PNG, 512 пикселей](../assets/logo.png); [исходник SVG](../assets/logo.svg) также включён. Для подготовленного разбора отдельные Actions, сервер и файл Knowledge не требуются. Доступные инструменты приложения можно настроить отдельно под выбранную задачу.
5. Выполни стартовые запросы в предварительном просмотре. Затем проверь новое определение, вывод по документу и просьбу вернуть точную копию. Сохрани запросы и ответы. Сопоставь исходные формулировки, добавленное прочтение, основания, разбор самого ответа и заданный формат.
6. Перед сохранением или публикацией проверь полный текст инструкции и аудиторию доступа. Сохранение не устанавливает выполнение инструкции в последующих ответах.

Файл Knowledge не заменяет поле Instructions. Не объединяй две языковые редакции и не сокращай текст молча. Исходная [сокращённая редакция](../../assets/medium.ru.txt) ограничена 5 000 знаков; подготовленный файл для GPT дополнительно включает область действия.

Решение о лицензии для двух пакетов плагинов записано в [LICENSING.md](../LICENSING.md).
