# Beforeword reader · 1.4.1

The remote MCP reader keeps exact writing beside a proposed reading. Connects to https://beforeword.xyz/mcp using Streamable HTTP without authentication. This is distinct from the native skills-only instruction package.

[Product](https://beforeword.xyz/reader/) · [Privacy](https://beforeword.xyz/reader/privacy/) · [Terms](https://beforeword.xyz/reader/terms/) · [Support](https://beforeword.xyz/reader/support/)

No account or model-provider call is made by the reader service. The host platform creates the reading. The exact core instruction is included after the workflow wrapper in skills/read/SKILL.md.
