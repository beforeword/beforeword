How it works
Select text and open Beforeword from the browser toolbar, or paste it here. Check the source and recipient. “Examine writing” or Ctrl/⌘ + Enter sends the selected passage. Then compare the excerpt and added explanation.
Paste writing here, then choose “Examine text”. This preview cannot capture other browser tabs.
          
A proposed explanation
The marks are proposed to be read here through learned writing conventions.
Writing does not become what it names.
This explanation and Beforeword’s words are written too.
Choose an excerpt to find it in the source. The added explanation is shown separately. It does not become what it names.
Ctrl + Enter or ⌘ + Enter sends the selected passage. Analyses stay available when you move between passages. Editing the text clears them.
The source page’s fonts and layout are not reproduced here.
There is no automatic analysis or message sending. An authored example is labelled separately from a model response.

      
Text and data
Text is sent only when you choose to analyse it.
The current text and analysis stay in this panel’s memory. Hiding or closing the side panel may leave it open in the browser. Reloading loses this panel state. Use Reset to clear it explicitly.
The latest selected fragment and an automatically issued temporary access session are kept in the browser session. Reset clears them. Only the language preference is saved between browser sessions.
The preview does not receive selections from other tabs. Reloading clears its text, analysis, and language choice.
Reset clears this panel and the captured selection. It does not delete copied text, downloaded files, or a request already sent.
