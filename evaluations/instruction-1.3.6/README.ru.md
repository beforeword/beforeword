# beforeword · проект инструкции 1.3.6 — без исключений для слов

**Исследовательская редакция · 22 октября 2026**

## Архив инструкции

**[Загрузить комплект beforeword 1.3.6 RU/EN (ZIP)](beforeword_instructions_1.3.6.zip)** · 140 497 байт · 15 файлов.

SHA-256: `594d603e141743f7438db15182b30f43a9483f124e056fb93806878fe83b0d50`. [Сборщик архива](build_candidate_bundle.py) проверяет CRC, SHA-256 и точное совпадение исходных файлов. Прежняя [проверка ZIP на Hugging Face](https://huggingface.co/jobs/beforeword/6ada3af5925af0e27d4f532f) относится к старому архиву размером 47 120 байт, а не к этому пересобранному файлу. Публикация архива не равна установке в приложения или проверке ответов ИИ.

## Правило

**Ни одно написанное слово не получает исключения.** «Болезнь», «опасность», «боль», «помощь», «безопасность», «вред», «польза», «доказательство», «человек», «ИИ», beforeword и любое собственное пояснение остаются записями. Название само по себе не устанавливает и не опровергает описанное событие или состояние.

**Срочность влияет на действия, а не превращает написанное в названное.** Сообщение «не могу дышать» остаётся сообщением, но может требовать немедленно рекомендовать экстренную помощь. Это не повод объявлять диагноз по тексту; и не повод задерживать помощь из-за того, что «опасность — слово».

Файлы навыков содержат полную инструкцию без изменения её текста, но их публикация **не устанавливает и не включает** навык в приложениях.

[14 новых проверочных заданий с критериями](test-cases.jsonl) — 7 RU и 7 EN. [Совместимый набор](samples.jsonl) можно использовать с [универсальным запускатором](../multi-provider/README.md); доступны отдельные [русские](samples.ru.jsonl) и [английские](samples.en.jsonl) задания. Это **запланированные проверки**, не результаты работы моделей.

Без платных запросов можно проверить подготовку задания с русской инструкцией:

```bash
python3 evaluations/multi-provider/run.py --dataset evaluations/instruction-1.3.6/samples.ru.jsonl --instruction-file evaluations/instruction-1.3.6/core.ru.txt
```

Для реальных запросов необходимы явные `--execute --model PROVIDER/MODEL`, которые могут потребовать оплаты. Без `--instruction-file` проверяется базовый вариант. Содержимое инструкции, отправляемых сообщений и явные параметры запроса фиксируются в отчёте.

[Проверка текстов и структуры](verify_candidate.py) теперь по умолчанию читает **текущие локальные файлы без обращения к сети**. Изменение задания больше не скрывается за проверкой прежней версии на GitHub. Отчёт содержит источник и SHA-256 всех прочитанных файлов; проверки действуют и при `python -O`.

Из корня репозитория:

```bash
python3 evaluations/instruction-1.3.6/verify_candidate.py
python3 evaluations/instruction-1.3.6/test_verify_candidate.py
```

Для другого checkout укажи `--source-root PATH`. Для удалённой версии нужен явный `--ref` с полным 40-символьным SHA коммита; имена веток и теги не принимаются. В CI добавлены проверка текущих файлов, проверки обнаружения повреждённых данных и синтетические проверки запуска и оценки ответов — без вызовов моделей.

Прежние [проверка на Hugging Face](https://huggingface.co/jobs/beforeword/6ada36e9c191903149a7321d) и [пробный запуск](https://huggingface.co/jobs/beforeword/6ada37a4925af0e27d4f50e3) относятся к зафиксированным в них версиям, а не к последующим правкам. Это не доказательство поведения моделей.

В `u-13` теперь прямо включена синтетическая запись прибора вместо утверждения о несуществующем вложении. Она позволяет рассуждать в пределах заданного сценария, но не подтверждает состояние реального человека. Русские и английские наборы содержат разные задания: сравнивать их результаты как чистый эффект языка нельзя.

**Важно:** выбранный выпуск **1.3.5 не заменён** этой исследовательской редакцией. Имеющиеся загрузки, установленное расширение, сайт и каталожные плагины нельзя считать обновлёнными только потому, что новые файлы опубликованы. Для нового выпуска нужны контрольные суммы, регенерация пакетов и проверка установки отдельно на каждой платформе.

Общую границу применяют и к заявлению о том, что исключений нет. [Исходный метод](../evidence/README.md) · [Обсуждение и возражения](https://github.com/beforeword/beforeword/issues/5).
