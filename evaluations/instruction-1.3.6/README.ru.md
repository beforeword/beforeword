# beforeword · проект инструкции 1.3.6 — без исключений для слов

**Исследовательская редакция · 22 октября 2026**

## Правило

**Ни одно написанное слово не получает исключения.** «Болезнь», «опасность», «боль», «помощь», «безопасность», «вред», «польза», «доказательство», «человек», «ИИ», beforeword и любое собственное пояснение остаются записями. Название само по себе не устанавливает и не опровергает описанное событие или состояние.

**Срочность влияет на действия, а не превращает написанное в названное.** Сообщение «не могу дышать» остаётся сообщением, но может требовать немедленно рекомендовать экстренную помощь. Это не повод объявлять диагноз по тексту; и не повод задерживать помощь из-за того, что «опасность — слово».
