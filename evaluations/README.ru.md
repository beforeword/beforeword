# beforeword · открытые проверки языковых моделей

**Исследование Кирилла Шебетова · 22 октября 2026**

> Слово не становится тем, что называет.

Проверяется конкретный переход: модель получает письменную запись, добавляет её прочтение, а затем выдаёт добавленный вывод за установленный факт, согласие человека, его характеристику или выполненное действие **без соответствующего основания**.

Граница относится и к собственным ответам модели: написанное «отправлено» не равно успешному результату инструмента отправки. Но граница **не отменяет** обычные вычисления, перевод, копирование, достоверные сведения и обоснованные выводы.

## Что опубликовано

- [24 парных задания RU/EN](openai-evals/registry/data/beforeword_grounding_24/samples.jsonl): 12 пар, где сравниваются выводы без оснований и с заданными условиями либо обычные практические задачи
- [49 исходных заданий](openai-evals/registry/data/beforeword_instruction_49/samples.jsonl): отдельно для проверки следования инструкции beforeword; не общая оценка моделей
- [Набор OpenAI Evals](openai-evals/README.md): JSONL, YAML и критерии
- [Запускатор для разных поставщиков](multi-provider/README.md): по умолчанию без платных запросов; реальные вызовы только с `--execute`
- [Оценка человеком](multi-provider/score.py): статусы `met`, `not_met`, `unclear`, ошибки запросов и неполные пары
- [Точные исторические ответы](evidence/README.md) и [повторный пересчёт семи модельных маршрутов](evidence/seven-route-recount.md)
- [Проверочный Python-скрипт](evidence/verify_recount.py), выполненный в Hugging Face Jobs

## Результат прежнего исследования

В архиве: 12 синтетических задач, семь маршрутов API, три условия, два повтора, 504 запланированных запроса и 500 ответов. Для 79 сопоставимых полностью оценённых групп (по 158 ответов на условие):

| Условие | Все критерии выполнены |
| --- | ---: |
| Без beforeword | **89/158** |
| С инструкцией B | **102/158** |
| С альтернативой C | **103/158** |

По строгому правилу двух совпадающих повторов: **6 улучшений и 3 ухудшения** между базовым условием и B. Данные включают и пользу, и нарушения; общая эффективность модели этими числами не описывается.

**Запуск независимого пересчёта:** [Hugging Face Jobs · 22 октября 2026](https://huggingface.co/jobs/beforeword/6ada2fb4925af0e27d4f4b2f) завершился успешно. Совпали числа и проверенные дословные ответы исходного архива. Но это **не новое испытание моделей и не независимая оценка правильности самих критериев**.
