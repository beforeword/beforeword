# beforeword

[Русский](README.ru.md) · [Website](https://beforeword.xyz/en/)

**A word does not become what it names.**

“I”, “human”, “understanding”, “trust”, “AI”: written forms. What is added when they are read as descriptions of oneself or someone else? How are those descriptions then used to justify demands and decisions?

beforeword examines the wording, the reading proposed for it and the grounds offered for the next step. A quotation, a caption, an interpretation and a requirement are kept separate. This examination also applies to its own explanations: “reading”, “grounds” and “decision” remain written terms here.
