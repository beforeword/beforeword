# beforeword

**English** · [Русский](https://github.com/beforeword/beforeword/blob/main/README.ru.md) · [Website](https://beforeword.xyz/en/)

**A word does not become what it names.**

beforeword is a research project by **Kirill Shebetov** examining how descriptions of people and AI are used to justify judgments, demands and decisions.

What is written? What interpretation is added? What justifies applying it to someone—and acting on it?

## Start here

1. **[Read the example below](#example)** — follow the steps from a written entry to a description and a proposed refusal.
2. **[Read the public proposal](https://github.com/beforeword/words-and-decisions)** — examine those steps while preserving the ability to object without accepting a description as who you are.
3. **[Explore the correspondence](https://github.com/beforeword/correspondence)** — 27 letters to researchers and AI companies, with English texts, Russian translations, purposes, sources and correspondence records.

## A short example

A form states **“Assignment not submitted.”** A response adds **“The applicant is unreliable,”** followed by **“Deny participation.”** This is a constructed example, not a reported incident.

The first entry does not contain the added description or the refusal. What grounds support each step? What rule permits the refusal? Can the person challenge either step without first accepting “unreliable” as who they are?

beforeword proposes examining the wording, interpretation and offered grounds separately. Its own explanations receive the same examination: using the words “grounds” or “rule” does not itself justify a conclusion.
